How the menu data is checked

One XML file follows two sets of rules: a DTD and an XML Schema. Both validate the same 12 dishes.

Week 6 · DTD

menu.dtd

Declares which elements an item must have, in what order, and the allowed values of the type attribute.

<!ELEMENT restaurant (item+)>
<!ELEMENT item (name, category, price,
                spicelevel, description)>
<!ATTLIST item
   id   CDATA #REQUIRED
   type (veg | nonveg) #REQUIRED>
Open file
Week 7 · XSD

menu.xsd

Adds data types: price must be a positive integer, and category and spice level must come from a fixed list.

<xs:element name="price"
     type="xs:positiveInteger"/>
<xs:element name="spicelevel"
     type="spiceType"/>
<xs:enumeration value="Extra Hot"/>

Weeks 8 – 9 · Data

menu.xml & menu.json

The XML is read with DOMParser; the JSON with response.json(). Both come from fetch().
